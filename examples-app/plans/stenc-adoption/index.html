Scope Check

Assessment

This plan covers Stenc adoption examples and renderer support as one documentation workflow.

Decomposition

No subsystem split is required for this example plan.

Architecture

Convert one canonical spec and one implementation plan into structured JSON, then render both through the fixed Stenc static app.

Tech Stack

  • Node.js
  • Dependency-free JSON validator
  • Static HTML renderer

Current State

Rail docs are plain Markdown with strong contracts but limited visual scanning support.

Target State

Rail docs use one JSON file per spec or plan and a fixed web page for human reading.

Scope

In

  • One canonical spec example
  • One implementation plan example
  • Thin AGENTS.md linkage if adopted in Rail

Out

  • Full docs migration
  • Runtime behavior changes
